**What it does**  
This program creates a new sorted folder named Favorites that holds the important/favorite files of a user.  
**How to run it**  
“python3 favorites.py add your-file  
python3 favorites.py list”  
In project folder to add a single file and view the contents of favorites or  
“python3 favorites.py add Test-files/\*  
python3 favorites.py list”  
To add an entire folder of files  
**How to run tests**  
“python3 \-m unittest \-v” in project folder
